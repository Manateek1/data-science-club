# Acalanes Data Fest 2026 — Instagram intro

An editable 14.4-second, 1080 × 1920 HyperFrames composition. It follows the
event site's white, Poppins, near-black, and Acalanes-blue visual system and
uses the site's Acalanes and BRIDGEGOOD logo files.

The copy uses the published event details: free, student-run, for Bay Area
high schoolers, in Oakland on November 21, 2026 from 9 AM to 5 PM. The ending
includes the site's registration URL. The export is silent so it can be paired
with Instagram audio when posted.

## Preview and render

Requires Node.js 22+ and FFmpeg/FFprobe on `PATH`.

```sh
npm install
npm run lint
npm run preview
npm run render
```

The finished MP4 is in `exports/acalanes-data-fest-intro-9x16.mp4`.
