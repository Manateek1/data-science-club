# Data Science Club

The public landing page for Acalanes Data Fest / Hackathon.

Live site: [acalanes-datafest.vercel.app](https://acalanes-datafest.vercel.app/)

Instagram: [@aca.datasci.club](https://instagram.com/aca.datasci.club)

## Contributing

Club members and visitors are welcome to contribute:

1. Fork this repository.
2. Create a branch for your change.
3. Make and preview your changes locally.
4. Open a pull request into `main` with a short description of what changed.

The event date, location, and registration details are intentionally marked TBD until the club confirms them.

## Project

This is a lightweight static site built with HTML, CSS, and vanilla JavaScript. The main files are:

- `index.html` for page structure and copy
- `styles.css` for layout and visual design
- `script.js` for navigation and reveal interactions
- `assets/data-field.png` for the hero artwork
