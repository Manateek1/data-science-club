# Contributing

Thanks for helping build the Data Science Club site.

## Pull requests

- Please work from a fork or a feature branch; `main` is protected.
- Keep pull requests focused and explain the change in the description.
- Check the page on desktop and mobile widths before opening a pull request.
- Do not commit passwords, API keys, tokens, or other private information.
- Keep the event details marked TBD until the club has confirmed them.

Maintainers review pull requests before anything is merged into the live site.
